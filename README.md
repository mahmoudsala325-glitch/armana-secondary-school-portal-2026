## 📖 نبذة عن المشروع (About The Project)

هذا المشروع هو البوابة الرقمية الرسمية التفاعلية لـ **مدرسة أرمنا الثانوية المشتركة** بمركز نصر النوبة بمحافظة أسوان، تم تصميمه وبناؤه ليعكس أصالة بلاد الذهب، ويوثق تاريخ المدرسة وتطورها ضمن المبادرة الرئاسية **«حياة كريمة»**، مع تقديم خدمات رقمية متطورة للطلاب وأولياء الأمور والمعلمين.

---

## ✨ المميزات الرئيسية (Key Features)

1. **🎨 هوية بصرية ملكية مستوحاة من درع المدرسة:**
   - تصميم بألوان الكحلي الملكي النيلي (`Imperial Sapphire Blue`) والذهب المصري المعتق (`Egyptian Antique Gold`).
   - خلفية بانورامية أصيلة لغروب شمس أسوان ونيل النوبة مع فلوكات وشراع النيل والزخارف النوبية الهندسية.

2. **🤖 المساعد الذكي لمدرسة أرمنا (AI Smart Assistant):**
   - مساعد تفاعلي مدعوم بنموذج Google Gemini مع قاعدة معرفية متكاملة عن تاريخ المدرسة، شعبها، مراحلها، وموقعها.
   - نظام حماية يمنع التخمين مع مسار بديل للتواصل الموثق.

3. **📢 نافذة وشريط أحدث الأخبار من صفحة فيسبوك (Live News Feed):**
   - شريط أخبار عاجلة متحرك في أعلى الموقع.
   - نافذة منبثقة تفاعلية تتيح تصفح المنشورات والقرارات وجداول الامتحانات والبحث فيها مع إمكانية نشر منشورات جديدة.

4. **🎖️ لوحة الشرف ولمسة الوفاء لرواد التعليم في أرمنا:**
   - **الأستاذ فيصل علي يونس:** المعلم المثالي لـ 3 سنوات متتالية، مدير المدرسة لمدة 3 سنوات، ورائد وضع اللبنة الأولى للتأسيس.
   - **الأستاذة صبرية أبو الفضل:** المديرة الثانية للمدرسة وصاحبة العطاء التربوي والإنساني الملهم في رعاية وتكريم الطلاب.
   - **الأستاذ أشرف عبد الباقي:** تقديرًا لسعيه ومساهمته المجتمعية المخلصة لإنشاء المدرسة لخدمة 20 ألف نسمة في 4 قرى.
   - تحية لرجالات القرية: الحاج عامر عابدين، الحاج عزت أبو السعود، والأستاذ أشرف عبد الدايم (رحمه الله - الغائب الحاضر).

5. **💻 فريق الإعداد والتطوير الطلابي:**
   - من إعداد الطلاب: **محمود عاشور، وعلوي علاء، وعارف يحيى، وأمير جمال، وميادة محمد**.
   - **تحت إشراف الأستاذة الفاضلة / هبة شيخ الدين**.

## 🛠️ التقنيات المستخدمة (Tech Stack)

- **Frontend:** React 19, TypeScript, Tailwind CSS (v4), Vite.
- **Backend:** Node.js, Express, TSX.
- **AI Integration:** `@google/genai` (Google Gemini API).
- **Icons & UI:** Lucide React, Canvas Confetti.

## 🚀 التشغيل السريع محلياً (Quick Start)

### المتطلبات الأساسية (Prerequisites):
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث).
- تثبيت مدير الحزم `npm`.

### 1. تثبيت الحزم (Install Dependencies):
```bash
npm install
```

### 2. إعداد المتغيرات البيئية (Environment Variables):
انسخ ملف `.env.example` إلى `.env`:
```bash
cp .env.example .env
```
*(اختياري)* ضع مفتاح `GEMINI_API_KEY` إذا كنت ترغب في تشغيل الذكاء الاصطناعي السحابي، علماً بأن النظام يعمل تلقائياً بقاعدة الردود الذكية المدمجة بدون مفتاح.

### 3. تشغيل وضع التطوير (Run Development Server):
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 4. بناء المشروع للإنتاج (Production Build):
```bash
npm run build
npm start
```

## 🚀 النشر على GitHub Pages

1. ارفع ملفات المشروع إلى مستودع GitHub عام باسم `armana-secondary-school-portal`.
2. من **Settings → Pages** اختر **GitHub Actions** كمصدر للنشر.
3. سير العمل الموجود في `.github/workflows/pages.yml` يبني الموقع وينشره مع كل تحديث لفرع `main`.

يكون الرابط `https://اسم-حسابك.github.io/armana-secondary-school-portal/`. يتطلب النشر المجاني مستودعاً عاماً. المساعد الذكي يعرض الرد الاحتياطي؛ تشغيل Gemini يتطلب استضافة الخادم `server.ts` بشكل منفصل.
